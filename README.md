# AK2_labs
Репозиторій, що містить матеріали до лабораторних робіт з дисципліни "Архітектура комп'ютерів 2. Процесори" студента групи ІО-42 Корсуна Богдана.
В лабораторній роботі №2, програма мовою C++ підтримує дані типи аргументів: help, version, list, value, list_values.
Для лабораторної роботи №4 додано hello.c та Makefile. 
Для лабораторної роботи №5 додано hello1.h, hello1.c, hello2.c та Makefile.
